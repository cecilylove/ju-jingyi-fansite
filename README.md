# 橘光集 · Orange Light · 鞠婧祎粉丝站

一个**纯静态、零依赖、零构建**的粉丝纪念/应援站点，手写原生 CSS + 原生 JS，开箱即看，可直接部署到 EdgeOne Makers（或任意静态托管）。

> ⚠️ 本项目为**非官方粉丝站**（橘光集 / Orange Light）。图片为微博 @鞠婧祎 公开营业图，仅供非商业纪念用途；上线前请确认素材授权，并保留站内「非官方声明」。详见文末《合规须知》。

---

## 一、目录结构

```
ju-jingyi-fansite/
├── index.html          # 首页
├── about.html          # 关于她
├── works.html          # 作品
├── gallery.html        # 图库
├── news.html           # 动态
├── update.html         # 动态详情页（按 ?id= 参数渲染，无需为每篇文章新建文件）
├── data/               # ★ 全站内容都在这里，改内容只改这几个文件
│   ├── site.js         # 站点外壳：站名 / 导航 / 页脚 / 合规声明 / 成长里程碑（所有页面都引）
│   ├── home.js         # 首页专属内容（仅 index.html 引）
│   ├── about.js        # 关于她：简介 / 应援信息 / 荣誉 / 区块标题
│   ├── works.js        # 作品：专辑、单曲、OST、电影、剧集、综艺、待播
│   ├── gallery.js      # 图库图片清单
│   └── news.js         # 动态：星河纪事时间线 + 文章正文
├── assets/
│   ├── css/styles.css  # 设计系统（改色 / 字体 / 圆角）
│   ├── js/main.js      # 渲染器 + 导航 / 滚动动画 / 灯箱
│   └── img/            # 图片素材（12 张）
├── AGENTS.md           # 给后续维护者（含 AI）的详细说明：渲染机制、数据字段表、常见任务
└── README.md
```

**核心设计：布局定死，内容外置。** 页面结构不动，改内容只改 `data/` 里的数据文件，不用碰 HTML。

## 二、本地预览

直接用浏览器打开 `index.html` 即可（`data/*.js` 用 `<script>` 引入，`file://` 下也能跑）。若需起服务：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

> 注意：导航、页脚和页面内容都由 JavaScript 渲染，**禁用 JS 会白屏**。这是“零依赖 + 数据驱动 + 本地双击可看”三者兼得的代价。

## 三、怎么改内容

**绝大多数改动只碰 `data/*.js` 一个文件。**

| 想改什么 | 改哪里 |
|---|---|
| 导航栏、页脚、合规声明、站名 | `data/site.js` |
| 成长里程碑（关于她页 + 首页共用） | `data/site.js` 的 `milestones`（**唯一源头**，首页自动截取前 4 条） |
| 首页首屏、作品卡、图库预览、应援档案 | `data/home.js` |
| 简介、应援信息、荣誉 | `data/about.js` |
| 作品（专辑 / OST / 电影 / 剧集 / 综艺 / 待播） | `data/works.js` |
| 图库图片 | `data/gallery.js` + 把图片放进 `assets/img/` |
| 动态时间线与文章 | `data/news.js` |
| 配色、字体、圆角 | `assets/css/styles.css` 的 `:root` |

### 加一条动态（含详情正文）

1. 在 `data/news.js` 的 `articles` 里加一项（`id` 建议用 `magazine-2027-01` 这种格式），正文写在 `body` 字段（HTML 字符串）
2. 若首页也要显示，在 `data/home.js` 里不用改——首页动态卡已与 `articles` **同源**，自动取前 2 条
3. 保存即可 → `update.html?id=你的id`

> 不用新建 HTML 文件。详情页的「上一篇 / 下一篇」按数组顺序自动生成。

### 换图片

把图片放进 `assets/img/`，然后在 `data/gallery.js` 的 `photos` 数组里加一行：

```js
{ src: 'assets/img/gallery-10.jpg', label: '营业图 · 十' }
```

> 文件名需真实存在，且**扩展名要与实际格式一致**（jpg / png / webp）。站点对图片格式不做转换。
> 图片较多时建议用腾讯云 COS + CDN 托管，避免塞进站点包（Makers 单函数包上限 128MB）。

### 改站名

站名分布在两类位置，改的时候**两处都要动**：

1. `data/site.js` → `meta.name` / `meta.nameEn`（导航栏与页脚，全站生效）
2. 6 个 HTML 的 `<title>` 与 `<meta name="description">`（这些是静态 SEO 标签，JS 渲染的内容搜索引擎读不到，必须写在 HTML 里）

## 四、部署到 EdgeOne Makers

> 前置：在 WorkBuddy 的「连接器」页连接 **EdgeOne Makers**（连接后需在 EdgeOne 控制台点「信任」启用）。

纯静态站点，Makers 自动以 `index.html` 为入口，三种方式任选：

**方式 A · Git 自动部署（推荐，最省心）**
1. 把本目录推到 GitHub / GitLab 仓库。
2. EdgeOne Makers 控制台 → 新建项目 → 连接该仓库。
3. 构建命令留空（纯静态无需构建），输出目录填 `.`（根目录）。
4. 每次 `git push` 自动构建并发布。

**方式 B · EdgeOne CLI**
```bash
npm install -g edgeone
cd ju-jingyi-fansite
edgeone pages deploy . --name juguangji
```

**方式 C · 控制台直接上传**：在 Makers 控制台选择「上传文件夹」，选中本目录即可。

### 绑定自定义域名 + ICP 备案

⚠️ **这一步决定国内能否正常访问。**

EdgeOne 项目默认加速区域是「全球可用区（不含中国大陆）」，此时**中国大陆网络访问会返回 401**，在微信内打开也会被拦截。要让国内秒开、微信分享正常，需要：

1. 在**境内注册商**（腾讯云 / 阿里云）购买域名 —— 境外注册商买的域名无法直接备案
2. 用**自己的实名信息**注册（备案要求域名持有者 = 备案主体）
3. 在腾讯云控制台提交 **ICP 备案**（免费，7–20 个工作日；个人非经营性站点无需营业执照）
4. 备案通过后，在 EdgeOne 控制台把加速区域切换为「**中国大陆可用区**」

> 备案期间可以先用「全球可用区（不含中国大陆）」把站点挂上试水，备案通过后再切换，**不用重买域名**。
> 站点全用相对路径（`assets/...`、`data/...`），**换域名不需要改任何代码**。

## 五、维护与自检

仓库内有两个自动化检查脚本，位于 `.workbuddy/`（已加入 `.gitignore`，不随仓库分发）：

| 脚本 | 层次 | 查什么 |
|---|---|---|
| `e2e-render-test.js` | 渲染层 | 用 jsdom 真实渲染全部页面，验证容器填充、条目数、脚本顺序、跨页文案一致 |
| `data-consistency-test.js` | 数据层 | 跨文件事实一致（同一事实在多处是否还对得上）、字段完整、单一源头不变量 |

改动数据后建议跑一次。**改了条目数量，需要同步更新脚本里的期望值**，否则会误报。
详细说明见 `AGENTS.md`。
